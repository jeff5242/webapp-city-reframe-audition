## 三、三個要請你們定奪的修正建議

1. **🔴 D 分項的季度覆蓋（合規重點）**：官方規定「每分項每期至少一查核點」。你們的 D 分項只有 D1(115/9)、D2/D4(116/9)、D3/D5(116/11)，**115/12、116/3、116/6 三期無 D 查核點**，可能被審查挑。上表已補三個 D 中間查核點（委外規格/合約→機制建置→內部弱掃）。若不想補，另一解是把資安/TrustAI 相關內部工作併入 C 分項、D 只留純委外檢測——請擇一。

2. **試辦件數改漸進**：原 C8~C11 每期都寫「【10】件完成」像複製貼上。已改為 **3→5→8→10 件累計**，比較合理且看得出進度。

3. **驗收標記**：已在各工作項目最後一個月的查核點標「驗收」（A2/C4→115/12、B3/C2→116/3、A8/B6→116/6、A6/C7→116/9、A13/B12/C11/D3/D5→116/11），符合「工作項目最後一月列驗收查核點」規定。
